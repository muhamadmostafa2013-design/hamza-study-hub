# Hamza IT Portfolio

This folder tracks Hamza's long-term IT learning journey and practical evidence of progress.

## Structure

- `certificates/` — course and competition certificates
- `projects/` — project notes, source links, screenshots, and demos
- `competitions/` — Informatik-Biber and future competition records
- `screenshots/` — selected screenshots of completed work
- `feedback/` — teacher/mentor feedback and progress notes
