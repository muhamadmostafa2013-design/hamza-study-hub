# Study Supervisor Agent

## Purpose

The Study Supervisor is a bounded parent-facing agent. It converts the evidence already stored by Hamza Study Hub into a short priority plan without changing school records or inventing missing facts.

## Inputs

- School update feed (`school_notifications.jsonl`)
- Evidence trust / canonical source generated by the existing intake pipeline
- Due dates and completion state from official sources
- Attention flags produced by the verifier
- Hamza's saved student-work attempts

## Internal stages

1. **Context scout** — normalize open assignments and saved learning attempts.
2. **Priority planner** — rank overdue, due-today, due-tomorrow, attention, and new work.
3. **Evidence verifier** — every proposed action must point back to a real evidence key from the input feed.
4. **Human gate** — community/user-imported evidence, missing instructions, and unknown deadlines are never promoted to facts; the report asks the parent to confirm them from an official source.
5. **Checkpoint store** — append-only JSONL run history preserves input fingerprint, output, confidence, and run id.

## Hard constraints

- Maximum five actions per run.
- Never mark school homework completed.
- Never alter WebUntis or Teams records.
- Never invent a due date.
- Never treat WhatsApp/community information as official.
- Completed assignments are excluded.
- A plan action is emitted only when its evidence key exists in the current feed.
- Identical inputs reuse the last checkpoint instead of generating noisy duplicate runs.

## Parent UI

The Home dashboard contains a **وكيل المذاكرة** card. It shows the current headline and first priority. **تشغيل الوكيل الآن** produces the complete parent brief and explicitly labels anything that needs confirmation.

## AI boundary

This first production slice is deterministic by design. The existing `AiReasoningProvider` can later be used for ambiguous explanation or natural-language coaching, but any model output must remain downstream of evidence collection and upstream of the deterministic verifier/gatekeeper. Model credentials must stay outside the APK.

## Verification

`StudySupervisorAgentTest` covers:

- due-today official work outranking later work;
- community evidence requiring parent confirmation;
- completed homework being excluded;
- missing deadlines remaining unknown rather than being fabricated.
