# Family homework agenda review

This review adds an offline Home summary of open homework due today, overdue, or without a usable due date. Future dated homework stays available through the existing homework list. Completed work and non-homework school messages are not counted. No school date, source flag, completion status, or stored data is changed. The existing next-homework selection remains intact. There is no new permission or integration.

## GitHub product references

- [UniTask](https://github.com/CondaLabs/unitask) (MIT): a local-first university planner with deadline buckets.
- [StudyAssistant](https://github.com/v1tzor/StudyAssistant) (Apache-2.0): a student planner with a home overview of workload.
- [Semester Desk](https://github.com/playxgaming/semester-desk-app): workload planning reference only; a repository license was not verified.

No source, strings, images, or assets from these projects are incorporated. Study Hub uses its own existing projection and date policy. Its proposed distinction is a caregiver workflow that retains schoolwork source/provenance while helping prioritize attention, not another generic planner.
